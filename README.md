<h1 align="center">STORM MULTIMEDIA</h1>

> 💡 **STORM MULTIMEDIA** — современный, быстрый и адаптивный мультимедийный веб-портал для онлайн-просмотра фильмов, сериалов, аниме и мультфильмов в высоком качестве (включая 4K Ultra HD), созданный в фирменной дизайн-системе экосистемы STORM SOFT.

---

## **Ключевые возможности и особенности**

- 🎬 **Агрегация источников контента**:
  - Каталог фильмов, сериалов и мультфильмов в 4K Ultra HD качестве с платформы **FanFilm4K**.
  - Каталог японской анимации, онгоингов и сезонов через интеграцию с сервисом **AniXart**.
  - Резервные мультиплееры **Kinobox**, **Kodik**, **Collaps** и **Alloha** с мгновенным переключением при сбоях и блокировках.
- 🎧 **Выбор озвучек и серий**:
  - Поддержка студий озвучивания для аниме и сериалов (AniLibria, AniDUB, SovetRomantica, Persona99, Студийная Банда и др.).
  - Мгновенная навигация по сериям с автозапуском выбранного эпизода.
- 👤 **Полноценная система аккаунтов**:
  - Регистрация, авторизация и сохранение сессий в защищённом хранилище SQLite.
  - Детальный профиль пользователя со статистикой: общее время просмотра в часах, количество завершённых и активных тайтлов.
- 🔖 **Менеджмент закладок и статусов просмотра**:
  - 6 фиксированных статусов: «Смотрю», «В планах», «Просмотрено», «Отложено», «Брошено» и «Любимое».
  - Отслеживание прогресса просмотра с процентной шкалой для каждого фильма или серии.
  - Синхронизация состояния «Продолжить просмотр» в реальном времени.
- 📁 **Пользовательские списки и коллекции**:
  - Создание персональных тематических подборок (например, «Марафон Marvel», «Любимое аниме»).
  - Быстрое добавление и удаление тайтлов из коллекций в один клик.
- 🎴 **4 режима отображения каталога**:
  - **Сетка карточек**: классические кинематографичные постеры с 3D-эффектом, шильдиками качества и прогресс-баром.
  - **Компактная сетка**: плотное расположение постеров для быстрого серфинга.
  - **Детальный список**: расширенные карточки с описанием сюжета, жанрами, рейтингами и прямым запуском.
  - **Таблица**: табличный вид для быстрого менеджмента большой медиатеки.
- 🎨 **8 эталонных тем оформления экосистемы STORM SOFT**:
  - STORM DARK (Тёмный кибер с акцентом Cyan `#00D2FF`)
  - STORM NIGHT (Глубокий чёрный OLED с чистым неоновым акцентом `#00F0FF`)
  - STORM DAY (Контрастная чистая светлая тема)
  - STORM MIDNIGHT (Аметистовая ночь)
  - STORM MATRIX (Матричный неоновый зелёный `#00FF66`)
  - STORM CYBERPUNK (Неон Найт-Сити `#FF007F`)
  - STORM FANTASY (Королевское золото `#F59E0B`)
  - STORM WARHAMMER 40K (Имперская готика `#D4AF37`)
- 🌐 **100% локализация интерфейса на 6 языков**:
  - Русский (RU), Английский (EN), Немецкий (DE), Французский (FR), Китайский (ZH), Японский (JA).
- 📱 **Полная адаптивность для ПК и мобильных устройств**:
  - Полноэкранный кинотеатральный режим для компьютеров.
  - Удобная нижняя панель навигации (Bottom Bar) для смартфонов и планшетов.

## **Инструкция по установке и запуску**

### Требования
- Установленная среда выполнения **Node.js 22** или выше (рекомендуется Node.js 26).

### Установка зависимостей
В корневой папке проекта выполните команду:
```bash
npm install
```

### Запуск портала
Для быстрого старта на Windows дважды кликните по файлу:
```text
start.bat
```
Либо запустите через терминал:
```bash
npm start
```

После запуска откройте в браузере адрес:
```text
http://localhost:3900
```
