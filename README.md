<h1 align="center">STORM MULTIMEDIA</h1>

> 💡 **STORM MULTIMEDIA** — современный кроссплатформенный мультимедийный портал и Android-приложение для комфортного просмотра фильмов, сериалов, аниме и мультфильмов в ультра-высоком качестве (включая 4K Ultra HD), созданный в фирменной дизайн-системе экосистемы STORM SOFT.

---

## **Ключевые возможности и особенности**

- 🎬 **Агрегация источников медиаконтента**:
  - Каталог фильмов, сериалов и мультфильмов в качестве 4K Ultra HD с платформы **FanFilm4K**.
  - Мировая база кинопроката и сериалов через интеграцию с **TMDB**.
  - Каталоги японской анимации и сезонов с сервисов **AniLibria**, **AniXart** и **Shikimori**.
  - Резервные мультиплееры **Kinobox**, **Kodik**, **Collaps**, **HDRezka**, **Alloha**, **VideoCDN**, **Ashdi**, **Vidsrc**, **Kinobaza** и **Kinogo**.
  - Торрент-стриминг раздач через **WebTorrent**, **RuTracker**, **NNM-Club** и **Rutor**.
- 📱 **Мобильное приложение для Android (APK)**:
  - Нативный полноэкранный режим от края до края (Edge-to-Edge) с автоматическим скрытием системных шторок (статус-бара и панели навигации).
  - Удобный нижний навигационный блок (Bottom Bar), оптимизированный под управление одной рукой.
  - Высокая плавность работы интерфейса с полным устранением повторных перерисовок и мерцаний.
  - Полноценная поддержка офлайн-библиотеки на базе IndexedDB.
- 📅 **Интеллектуальный календарь релизов и расписание серий**:
  - Агрегация актуального графика онгоингов из официальных API **AniLibria**, **TMDB** и **Shikimori**.
  - Точное время выхода новых эпизодов по московскому времени (МСК), номера сезонов и серий.
  - Отображение студий озвучивания и дубляжа (LostFilm, Red Head Sound, AniLibria, HDRezka, TVShows).
  - Векторные кинематографичные афиши-заглушки и каскадное восстановление при сетевых ограничениях.
- 📺 **Интерфейс Smart TV (10-Foot UI)**:
  - Специализированный режим для телевизоров и ТВ-приставок на базе Android TV.
  - Полная поддержка навигации с помощью пультов дистанционного управления, клавиатур и геймпадов.
- 🧠 **ИИ-советник STORM NEURAL RECOMMENDER**:
  - Персональные интеллектуальные рекомендации кинолент и сериалов на вечер на основе истории просмотров и вкусовых предпочтений.
- 👥 **Кинозал совместного просмотра (Watch Together)**:
  - Синхронный онлайн-просмотр видеопотока с друзьями, встроенный чат и управление воспроизведением.
- 📱 **Пульт дистанционного управления STORM REMOTE**:
  - Управление воспроизведением на компьютере или ТВ прямо со смартфона через сканирование QR-кода без установки сторонних утилит.
- 👑 **Семейные профили и детский режим**:
  - Разделение профилей для каждого члена семьи с независимыми закладками и историей.
  - Безопасный детский режим с автоматической фильтрацией контента категории 18+.
- 🎴 **4 режима отображения каталога**:
  - **Сетка карточек**: объёмные кинематографичные постеры с 3D-эффектом, индикаторами качества и шкалой просмотра.
  - **Компактная сетка**: плотное отображение обложек для быстрого просмотра каталога.
  - **Детальный список**: карточки с описанием сюжета, списком жанров, рейтингами и прямым запуском.
  - **Таблица**: структурированный табличный вид для удобной работы с обширной коллекцией.
- 🎨 **8 эталонных тем оформления экосистемы STORM SOFT**:
  - **STORM DARK** (Тёмный кибер с акцентом Cyan `#00D2FF`)
  - **STORM NIGHT** (Глубокий чёрный OLED с чистым неоновым акцентом `#00F0FF`)
  - **STORM DAY** (Контрастная чистая светлая тема)
  - **STORM MIDNIGHT** (Аметистовая ночь)
  - **STORM MATRIX** (Матричный неоновый зелёный `#00FF66`)
  - **STORM CYBERPUNK** (Неон Найт-Сити `#FF007F`)
  - **STORM FANTASY** (Королевское золото `#F59E0B`)
  - **STORM WARHAMMER 40K** (Имперская готика `#D4AF37`)
- 🌐 **100% локализация интерфейса на 6 основных языков**:
  - Русский, Английский, Немецкий, Французский, Китайский, Японский.

## **Установка и запуск**

### Мобильное приложение для Android
1. Загрузите установочный файл **STORM_MULTIMEDIA_1.0.0.apk** из раздела релизов.
2. Откройте загруженный файл на устройстве Android и подтвердите установку.
3. Запустите приложение для просмотра контента в полноэкранном режиме.

### Запуск веб-портала из исходного кода

#### Требования
- Среда выполнения **Node.js 22** или выше (рекомендуется Node.js 24+).

#### Установка зависимостей
В корневой папке проекта выполните команду:
```bash
npm install
```

#### Запуск портала
Для быстрого запуска в Windows дважды кликните по файлу:
```text
start.bat
```
Либо выполните команду в консоли:
```bash
npm start
```

После старта веб-интерфейс доступен в любом браузере по адресу:
```text
http://localhost:3900
```
